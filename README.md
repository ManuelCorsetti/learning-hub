# Learning Studio

A React/Vite template for a personal learning library. Articles are defined as data in `src/main.jsx`, so new topics can be added by composing sections, examples, callouts and visuals without duplicating the page shell.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The first article is a dimensional-modelling study aid adapted from the attached HTML and grounded with examples relevant to BigQuery and marketing decisioning.
